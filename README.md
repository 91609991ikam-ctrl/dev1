# 🎨 カラーパレット抽出アプリ

イラスト・絵画・写真などの画像から、使われている色を抽出して数色のカラーパレットを
作成する Web アプリ（プロトタイプ）です。大学時代の研究で開発していた手法を再現しています。

## 手法（処理の流れ）

1. **画像を入力**（アップロード）
2. （任意・既定ON）**領域分割（スーパーピクセル）を前段に**かける
   - Felzenszwalb（既定・速くて内容に沿う）/ Quickshift / SLIC で色の近い小領域にまとめ、
     **各領域の平均色**を色分析の入力にする
   - 小さな鮮やか領域を面として拾い、にじみノイズを均す。**境界オーバーレイと領域平均色マップ**で
     分割結果を確認できる（粒度が粗いと小さな色が平均で消えるので、必要なら粒度を調整）
3. ピクセルの色を **k-medoids**（教師なし学習）で**固定クラスタ数 k**（既定 16）に減色する
   - 代表色に**実在画素（medoid）**を使うため、平均（k-means の重心）で生じる色のくすみを避ける
   - 距離は **CIELAB（ΔE）** で計算（知覚的に分割。赤と背景が分かれやすい）。
     サイドバーで RGB 距離にも切替可能
   - **先端寄せ（彩度重み γ=2、既定ON）**: 表示する代表色を彩度 C² 重みで高彩度側に寄せ、
     くすみを抑える（表示のみ。割合・アクセント判定は medoid のまま）
   - 距離行列が O(n²) になるため、学習は部分標本で行い全画素を最近傍 medoid に割当
3. 各クラスタ中心を**基本色名（赤・橙・黄・緑・青・紫・桃・茶・白・灰・黒）に分類**し、
   同じ色名のクラスタの**割合を合算（集約）**する
   - 既定は **人間の色名データ（XKCD Color Survey・CC0）の k 近傍多数決**で判定。
     無彩色⇔有彩色の境界が人の色名分布から決まるため、**暗い/くすんだ有彩色が
     黒・灰に誤判定されにくい**（旧: 基本色アンカーへの最近傍にも切替可）
   - **地味・くすんだ色は「茶」に統一**（XKCD の brown/mud/dull 等の名前を茶に割当）。
     赤/青/緑などの鮮やかな色と区別され、**茶は白・灰・黒と同じくアクセント対象外**
   - これにより、知覚的に同じ「赤」でも `#FE0501`・`#EB1419`… と分裂していた色がまとまり、
     アクセントカラーが安定して出やすくなる
   - 各色名の代表色（見本）は、そのグループの加重平均色に最も近い**画像に実在する画素色**を採用
4. 集約後の割合を**多い順（降順）**に並べ替える
5. 割合が **0〜10%**（既定）の色を「**アクセントカラー**」と定義する
   - 既定では**無彩色（白・灰・黒）はアクセント対象外**（サイドバーで切替可能）
   - **アクセント判定モード**（サイドバーで切替）:
     - **絶対**（現行）: 割合帯＋有彩色＋**コントラスト条件**（主要色から色差 ΔE が閾値以上）
     - **① 相対**: 画像全体の彩度分布に対する**外れ値**で判定。白っぽい画像でも
       “相対的に色みのある”淡い色を拾える
     - **② 正規化**: 画像ごとに彩度を引き伸ばしてから判定（無彩色は引き伸ばさない）
   - 色名判定は**淡色でも色相名を付ける**（彩度が低いだけの色を白/灰に流さない）よう改善
6. 固定クラスタ数 k で**減色（量子化）した画像**を入力画像の下に表示する
   - 各画素を所属クラスタの中心色に置き換えた画像
7. 固定クラスタ数 k のカラーパレットを作成し、表示する（**割合の小さい順**に描画）
   - パレットは**集約せず実際の k 個のクラスタ色**をそのまま表示（k=16 なら最大16色）
   - アクセントの印付けだけは集約ベースの判定結果（どの基本色名がアクセントか）に従う
   - **横向きの積み上げ棒グラフ**（幅＝割合）＋ **丸（その色）＋色名＋16進数＋割合** の凡例（アクセントは ⭐）

> 注: 「アクセントが出る最小クラスタ数を二分探索で探す」機能（`find_min_accent_k`）は
> コードには残していますが、現在アプリは**固定 k での判定**を既定にしています。

## セットアップ

```bash
pip install -r requirements.txt
```

## 起動

```bash
streamlit run app.py
```

ブラウザが開いたら画像をアップロードしてください。**複数ファイルをまとめて選択でき**、
選んだ画像すべてに対して処理し、ファイルごとに結果（入力画像・減色画像・パレット）を
表示します（ファイル選択ダイアログでフォルダ内を全選択すれば一括処理になります。
ブラウザの仕様上フォルダそのものの指定はできません）。サイドバーで次のパラメータを調整できます。

| パラメータ | 説明 | 既定値 |
|---|---|---|
| 知覚的距離 CIELAB で分割 | ON で距離を ΔE、OFF で RGB | ON |
| アクセントカラーの範囲 | この割合に入る色をアクセントとみなす | 0〜10% |
| 初期クラスタ数 (k_max) | 最初にアクセントを定義するクラスタ数 | 16 |
| 最小クラスタ数 (k_min) | 探索する最小のクラスタ数 | 2 |
| サンプリング上限ピクセル数 | 速度のため画像を縮小してから処理 | 50,000 |
| 乱数シード | 再現性のため固定 | 42 |

## ファイル構成

| ファイル | 役割 |
|---|---|
| `segmentation.py` | 前段の領域分割（Quickshift / SLIC / Felzenszwalb）。領域平均色マップ・境界オーバーレイも生成。 |
| `clustering.py` | 軽量 k-medoids（部分標本＋交互最適化、CIELAB 距離）。代表色に実在画素を使い色のくすみを避ける。sklearn 互換 API。 |
| `color_naming.py` | 色名判定（人間の色名データの k 近傍／基本色アンカー最近傍）・sRGB→CIELAB 変換。 |
| `color_names_data.py` | XKCD Color Survey（CC0）から生成した色名データ（実行時 matplotlib 非依存）。 |
| `color_palette.py` | コアロジック（クラスタリング・基本色名への集約・割合算出・アクセント定義・最小 k 探索）。UI 非依存で再利用可能。 |
| `app.py` | Streamlit の Web UI（横棒グラフ＋丸の凡例）。 |
| `color_space.py` | 診断用: 画像の色を RGB / CIELAB の 3D 散布図にする（medoid 重ね・色切替）。CLI とコード両対応。 |
| `color_space_app.py` | 診断用の別 Streamlit アプリ。画像をアップして色分布を 3D で回転・観察できる（メインの `app.py` とは独立）。 |
| `requirements.txt` | 依存ライブラリ。 |

## 診断ツール: 色の 3D 空間プロット

「なぜ色がくすむのか」を直接見るための、メインアプリから独立した可視化ツール。

```bash
streamlit run color_space_app.py          # ブラウザで回転・観察
# または CLI で HTML 書き出し:
python color_space.py 画像.png --k 16 --out plot.html
```

各画素をその色で点描し、k-medoids の代表色（◆）を重ねる。ボタンで点の色を
「実際の色 / 割り当て代表色」に切り替えると、量子化で鮮やかな色がどの代表色に
潰れているか（くすみの原因）が空間的に分かる。

## コアロジックの利用例（スクリプトから）

```python
from PIL import Image
from color_palette import load_pixels, find_min_accent_k

img = Image.open("input.png")
pixels = load_pixels(img)
result = find_min_accent_k(pixels, accent_low=0.05, accent_high=0.10)

print("最小クラスタ数:", result.min_k)
print("探索の経過:", result.trace)  # 例: [(8, True), (4, False), (6, True), (5, True)]
for c in result.final_palette.colors:
    mark = "⭐アクセント" if c.is_accent else ""
    print(f"{c.name}  {c.hex}  {c.percent:.1f}%  {mark}")
```

`find_min_accent_k(..., aggregate=False)` とすると、基本色名への集約をせず
各クラスタをそのまま 1 色として扱う従来動作になります（手法比較・評価用）。

## 補足・既知の制約

- アクセント抽出の述語 P(k)=「k クラスタでアクセントが出るか」は厳密には単調とは
  限らないため、二分探索は近似的な探索です（ユーザー指定により二分探索を採用）。
  全クラスタ数を試したい場合は線形探索への切り替えも容易です。
- 色名への近似は **CIELAB の ΔE76（Lab 上のユークリッド距離）** で最近傍判定して
  います。より厳密な知覚距離が必要なら ΔE2000 への差し替えが可能です（今後の改善候補）。
- 基本色名のアンカー色（代表色）の選び方で分類結果が変わります。`color_naming.py` の
  `BASIC_COLORS` の表を編集して調整できます。
- 主要色がほぼ均等（例: 33%ずつ）で、アクセント範囲（既定 0〜10%）に入る色が
  無い画像では「アクセントカラーは見つかりませんでした」と表示されます（仕様どおり）。
