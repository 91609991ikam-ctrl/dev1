# 🎨 カラーパレット抽出アプリ

イラスト・絵画・写真などの画像から、使われている色を抽出して数色のカラーパレットを
作成する Web アプリ（プロトタイプ）です。大学時代の研究で開発していた手法を再現しています。

## 手法（処理の流れ）

1. **画像を入力**（アップロード）
2. ピクセルの色を **K-means クラスタリング**（教師なし学習）で減色する（初期クラスタ数 = 16）
3. 各クラスタ中心を **CIELAB の色差 ΔE で最も近い基本色名（赤・橙・黄…10色）に近似**し、
   同じ色名のクラスタの**割合を合算（集約）**する
   - これにより、知覚的に同じ「赤」でも `#FE0501`・`#EB1419`… と分裂していた色がまとまり、
     アクセントカラーが安定して出やすくなる
   - 各色名の代表色（見本）は、そのグループの加重平均色に最も近い**画像に実在する画素色**を採用
4. 集約後の割合を**多い順（降順）**に並べ替える
5. 割合が **5〜10% 付近**の色を「**アクセントカラー**」と定義する
   - 既定では**無彩色（白・灰・黒）はアクセント対象外**（サイドバーで切替可能）
6. 定義したアクセントカラーが抽出できる**最小クラスタ数**を、
   様々なクラスタ数でクラスタリングして**二分探索**で探す
   - 例: 16(定義) → 8 → 4(抽出できない) → 6(できた) → 5(できた) ⇒ 最小は 5
7. 最小クラスタ数 k で**減色（量子化）した画像**を入力画像の下に表示する
   - 各画素を所属クラスタの中心色に置き換えた画像
8. 最小クラスタ数 k のカラーパレットを作成し、表示する（**割合の小さい順**に描画）
   - パレットは**集約せず実際の k 個のクラスタ色**をそのまま表示（k=8 なら 8 色）
   - アクセントの印付けだけは集約ベースの判定結果（どの基本色名がアクセントか）に従う
   - **横向きの積み上げ棒グラフ**（幅＝割合）＋ **丸（その色）＋色名＋16進数＋割合** の凡例（アクセントは ⭐）

## セットアップ

```bash
pip install -r requirements.txt
```

## 起動

```bash
streamlit run app.py
```

ブラウザが開いたら画像をアップロードしてください。サイドバーで次のパラメータを調整できます。

| パラメータ | 説明 | 既定値 |
|---|---|---|
| アクセントカラーの範囲 | この割合に入る色をアクセントとみなす | 5〜10% |
| 初期クラスタ数 (k_max) | 最初にアクセントを定義するクラスタ数 | 16 |
| 最小クラスタ数 (k_min) | 探索する最小のクラスタ数 | 2 |
| サンプリング上限ピクセル数 | 速度のため画像を縮小してから処理 | 100,000 |
| 乱数シード | 再現性のため固定 | 42 |

## ファイル構成

| ファイル | 役割 |
|---|---|
| `color_naming.py` | 色の近似ロジック（基本色名のアンカー・sRGB→CIELAB 変換・ΔEで最近傍色名）。アンカー色は表を編集するだけで調整可能。 |
| `color_palette.py` | コアロジック（クラスタリング・基本色名への集約・割合算出・アクセント定義・最小 k 探索）。UI 非依存で再利用可能。 |
| `app.py` | Streamlit の Web UI（横棒グラフ＋丸の凡例）。 |
| `requirements.txt` | 依存ライブラリ。 |

## コアロジックの利用例（スクリプトから）

```python
from PIL import Image
from color_palette import load_pixels, find_min_accent_k

img = Image.open("input.png")
pixels = load_pixels(img)
result = find_min_accent_k(pixels, accent_low=0.05, accent_high=0.10)

print("最小クラスタ数:", result.min_k)
print("探索の経過:", result.trace)  # 例: [(8, True), (4, False), (6, True), (5, True)]
for c in result.final_palette.colors:
    mark = "⭐アクセント" if c.is_accent else ""
    print(f"{c.name}  {c.hex}  {c.percent:.1f}%  {mark}")
```

`find_min_accent_k(..., aggregate=False)` とすると、基本色名への集約をせず
各クラスタをそのまま 1 色として扱う従来動作になります（手法比較・評価用）。

## 補足・既知の制約

- アクセント抽出の述語 P(k)=「k クラスタでアクセントが出るか」は厳密には単調とは
  限らないため、二分探索は近似的な探索です（ユーザー指定により二分探索を採用）。
  全クラスタ数を試したい場合は線形探索への切り替えも容易です。
- 色名への近似は **CIELAB の ΔE76（Lab 上のユークリッド距離）** で最近傍判定して
  います。より厳密な知覚距離が必要なら ΔE2000 への差し替えが可能です（今後の改善候補）。
- 基本色名のアンカー色（代表色）の選び方で分類結果が変わります。`color_naming.py` の
  `BASIC_COLORS` の表を編集して調整できます。
- フランス国旗のように主要色がほぼ均等（33%ずつ）の画像では、5〜10% に入る色が
  無いため「アクセントカラーは見つかりませんでした」と表示されます（仕様どおり）。
